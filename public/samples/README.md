# Public FITS test images

Downloaded from the Astropy project's public astropy-data repository on 2026-11-08. Original files are preserved byte-for-byte; see provenance.json for source URLs and SHA-256 checksums.

- horsehead.fits: tutorials/FITS-images/HorseHead.fits. 891 × 893 pixels. Header identifies STScI/MAST Digitized Sky Survey, UK Schmidt telescope; DATE-OBS 1990-12-22T13:49:00. Contains TAN celestial WCS.
- galactic-center-2mass-j.fits: galactic_center/gc_2mass_j.fits. 721 × 720 pixels. 2MASS J-band Galactic Center tutorial image. Contains TAN celestial WCS.

Source index: https://www.astropy.org/astropy-data/
